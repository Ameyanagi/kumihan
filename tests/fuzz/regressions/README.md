# Parser regression corpus

All starting fonts are generated by `tests/support/font_fixture.mojo` under
Kumihan's MIT OR Apache-2.0 license. No third-party font files are needed.

The campaign replays every checked-in `*.bin` here before mutations. For a
non-security crash or hang, copy its exact `.pixi/fuzz-failures/<sha256>.bin`
and matching JSON metadata here, minimize a separate copy if useful, and add
a focused Mojo regression before fixing the parser. Preserve the original
failing bytes and seed. For a potential vulnerability follow `SECURITY.md`
and keep the reproducer private until coordinated disclosure is appropriate.

There were no crash/hang fixtures when this campaign was introduced.
